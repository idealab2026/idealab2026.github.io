# GCP plan — no billing or credentials activated
Checked 2026-11-28: https://docs.cloud.google.com/free/docs/free-cloud-features and https://docs.cloud.google.com/bigquery/docs/sandbox .
Cloud Run request-based free allowance: 2M requests, 180k vCPU-seconds and 360k GB-seconds memory monthly; active billing required, overages and image storage possible. Do not deploy. The previous API Cloud Run manifest is prepared; this gateway additionally needs upstream reachable services, distributed metrics/rate storage and real IAM. SQLite on Cloud Run is ephemeral and not a distributed limiter. No server deployment until architecture/security/budget authorization.
BigQuery sandbox: no credit card or billing account; 10 GiB storage, 1 TiB monthly query processing, limited functionality, automatic expiration; streaming unavailable. Export authenticated /v1/metrics/export to NDJSON and batch load manually into a confirmed billing-disabled institutional sandbox; schema ts TIMESTAMP, project/model/mode/scope STRING, status INTEGER, latency_ms FLOAT, input_tokens/output_tokens INTEGER NULLABLE, prompt_version/prompt_sha256 STRING NULLABLE. Query bigquery.sql; never mix ci_test and local_demo. No BigQuery project has been created or queried in this work.
Cloud Storage: free storage/operations within eligible US regions and limits; billing required. Local cache volume and reviewed artifacts only.
Artifact Registry: 0.5 GB storage allowance; billing required. Existing Distribution local registry demo is not Artifact Registry.
Cloud Logging: first 50 GiB logs/project/month under allowance; billing required for free tier. Gateway outputs structured JSON without prompt text or keys; Cloud Run would collect stdout/stderr. Do not send sensitive logs.
IAM: no additional charge for IAM itself (https://cloud.google.com/iam/pricing); no roles created. Design dedicated service identities, roles/run.invoker only to permitted callers, roles/artifactregistry.reader on the relevant repository, bucket-scoped storage object viewer, BigQuery jobUser and dataset-scoped dataEditor only for ingestion identity. Avoid service account keys; use workload identity/ADC. Current app API keys are not IAM.
Vertex AI / Gemini Enterprise Agent Platform: paid model inference/training generally, see https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing . Study model endpoints, Model Garden, model registry and managed pipelines; no service enabled.
GKE: free cluster management credit does not cover compute/network; use existing kind demo. See https://docs.cloud.google.com/free/docs/free-cloud-features .
